# jobdeck-job-api

## Database schema

[Schema documentation and Mermaid ER diagrams](docs/schema/README.md) are
versioned Markdown generated by tbls from `db/job/migrations`. Do not edit the
generated files manually. CI regenerates them and rejects tracked or untracked
drift with `make check-clean`.

After `make setup`, install PostgreSQL 18 server/client tools locally, then run:

```sh
make schema-docs
# If pg_config selects another PostgreSQL installation:
PG_BIN=/usr/lib/postgresql/18/bin make schema-docs
```

This creates a new private temporary cluster, applies every goose migration,
generates only the `job` schema (tables, views, constraints, indexes and
relations), then stops and removes the cluster, including on failure. Run as a
non-root user. No existing database or production URI is used. Server build
metadata is omitted from `schema.json` to keep output portable.

For an interactive [Liam ERD](https://liambx.com/docs/parser/supported-formats/tbls)
view of the same versioned `schema.json`, install Node.js/npm and run:

```sh
make schema-erd
npx --yes http-server@14.1.1 tmp/schema-erd -a 127.0.0.1 -p 8080 -c-1
```

Open `http://127.0.0.1:8080` (not `file://`). Liam CLI is pinned in the Makefile;
the disposable HTML/assets under `tmp/schema-erd` are ignored. No deployment or
GitHub Pages setup is required.
